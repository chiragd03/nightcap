# Security

## Reporting a problem
Please **don't** open a public issue for security problems.

Report privately through GitHub: go to the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, which part and version it affects, and how to reproduce it.

You'll get a reply as soon as possible. Once a fix is out, we're happy to credit you in the release notes if you'd like.

## Supported versions
Fixes go into the newest release of each part (setup tool, server, Android TV, Samsung and LG apps). Please update to the newest release before reporting.

## Keeping your server safe
- Keep the owner key secret; it's the admin password for your server.
- Update regularly: run `nightcap` and choose **Update**.
- If you open your server to the internet, use https.
