# Getting help

- **Questions, setup help and ideas:** [Discussions](https://github.com/chiragd03/nightcap/discussions).
- **Something is broken:** open a [bug report](https://github.com/chiragd03/nightcap/issues/new/choose).
- **A security problem:** see [SECURITY.md](SECURITY.md).

When asking, say which part you're using (setup, server, web app, Android TV, Samsung, LG), its version, and where the server runs (this computer, Kubernetes, Google Cloud or another machine). For server problems, the logs help: run `nightcap`, pick your server, then **Logs**.
