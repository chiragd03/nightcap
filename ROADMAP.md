# Roadmap

What's being built next. Nothing here has a date; things move up when they're ready and tested.
Ideas and votes are welcome in [Discussions](https://github.com/chiragd03/nightcap/discussions).

## Setup and running the server
- **Windows one-line install:** install with one command instead of a manual download.
- **Built for ARM computers:** a server image made for Apple Silicon and Raspberry Pi (today they run it translated).
- **Setup in your browser:** the same guided setup, opened in a web browser (`nightcap --web`).
- **More clouds:** AWS, Fly.io and Railway as more places to run the server.
- **Change settings later:** change the server's name, country and keys after setup.
- **Back up from the terminal:** export every household to a file without leaving the terminal.
- **One-click https at home.**

## On the TV
- **In your TV's app store:** install Nightcap straight from the Google TV, Samsung and LG stores.
- **Voice search button:** a microphone button inside Nightcap.
- **Chromecast support:** cast from your phone to a Chromecast.
- **Samsung's own player:** Samsung's built-in player engine, for even more file types on Samsung TVs.

## Households and profiles
- **Kids profiles:** profiles that show only titles suited to children.
- **Profile lock:** lock a profile so only its owner can open it.
- **Year in review:** a look back at everything you watched.

## Watching
- **Remind me when it's out:** get told when an upcoming film or show arrives.
- **Picks for this hour:** hour-by-hour picks of the Live TV channels you usually watch at that time.
- **Full sound in every browser:** Dolby and DTS in Safari and Firefox, and Atmos tracks in the browser.
- **More Top 10 countries.**
